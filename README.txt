## Kostenlos veröffentlichen
Du kannst diese einzelne statische HTML-Datei z. B. über GitHub Pages hosten.

1. Neues öffentliches GitHub-Repository anlegen, z. B. `salahfocus-privacy`.
2. `privacy-policy.html` hochladen.
3. GitHub Pages für den Branch `main` aktivieren.
4. Optional die Datei zusätzlich als `index.html` verwenden.
5. Die endgültige öffentliche HTTPS-Adresse in SalahFocus als `PRIVACY_POLICY_URL`
   und in App Store Connect / Google Play Console eintragen.

## Technische Grundlage
Der Text basiert auf dem Privacy-Audit der geprüften SalahFocus-Version:
- Standort optional für Gebetszeiten/Qibla.
- Koordinaten/Berechnungsparameter können an api.aladhan.com übertragen werden.
- Geocoding kann über Plattformanbieter laufen.
- Gebets-/Ramadan-Historie bleibt lokal.
- Kein SalahFocus-Account/Backend.
- Keine Analytics-/Werbe-/Tracking-SDKs im geprüften Stand.

Wenn sich App-Funktionen, SDKs, APIs oder Datenflüsse ändern, muss die
Datenschutzerklärung erneut geprüft werden.

Hinweis: Dies ist eine technische Vorlage und keine individuelle Rechtsberatung.
